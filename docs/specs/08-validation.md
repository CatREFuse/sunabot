## 11. 验证标准

场域知识专项必须覆盖 `AIR.md` 缺失初始化、64 KiB 上限、必需章节、符号链接拒绝、revision 冲突与原子替换；`read_air` 只接受严格的 `insight` 参数，并在一次更新中同时获得原有场域知识、当前会话范围及最近聊天记录、角色注入理解。运行时回归必须证明显式称呼、反感、禁忌、边界、群规和已解释私梗会触发可用工具，prompt override 不获得更新端口，成功写入后当前人格热重载，跨 Agent 与跨会话内容不串用，冲突重试仍保持单文件完整。提示词回归必须覆盖 `persona.air`、`air.knowledge`、`air.conversation`、`air.insight` 的目录登记，公共与 Agent override 的 `read_air.json`，旧自定义私聊和群聊模板一次性补变量与 canonical tool 后不再回填，以及管理员自定义消息顺序、角色、工具和 response format 保留。管理台必须验证“场域知识”“读空气提示词”和“读空气”工具目录项在桌面、移动端、light 与 dark 模式下可见可编辑。

会话工具策略必须覆盖 QQ 私聊、群聊和 `web:admin` 的独立 SQLite 重载，旧会话缺少字段时默认全部跟随 Agent，总开关关闭后会话不能重新启用。API 负例必须覆盖未知工具、重复工具、非数组、多余字段和无效会话 ID；Provider 回归必须证明会话停用会同时移除工具定义、执行模式和实际调用能力，伪造 Function Call 零副作用。管理台 E2E 与视觉检查必须覆盖每条会话列表项、会话详情和 Web Chat 的独立设置入口，QQ 会话的回复与群聊编排器设置，QQ 与 Web Chat 的工具权限，Agent 已停用锁定、会话间隔离、防抖与同实例串行同步、失败保留输入并阻止离页、深链刷新、返回原会话，以及桌面/移动端 light/dark 页面。页面不得显示通用保存、放弃、未保存标记或离页确认。延迟请求回归必须证明切换会话或 Agent 后旧工具目录、旧草稿及迟到的成功或失败响应均不会显示或写入新上下文，工具数据就绪前不能切换；工具同步只能提交严格的 `disabledTools` 数组。

知识库专项必须覆盖嵌套目录递归顺序、未知扩展和符号链接忽略、文件数与深度上限、JSONL 每个非空物理行分段、Markdown/文本自然段分段、BOM/CRLF、无效 UTF-8、超限文件、硬链接、读取中身份变化，以及增量同步、删除源文件和全量重建。检索必须证明 FTS5 `bm25` 排序、中英文 token、路径命中、limit 边界、当前 Agent 隔离、相对路径与精确行号、正文截断和伪造未声明工具零执行。管理 API 必须覆盖 list/search/reindex、Markdown 嵌套上传、同路径冲突、路径穿越、非法 Unicode、非 Markdown、空正文、超限正文和安全删除；管理台必须覆盖 Agent 切换迟到响应、搜索、上传、删除、重建，以及 390/1440 light/dark 页面和弹层无横向溢出。

Web Search 证据专项必须覆盖晚于模型知识截止日期的陌生官方产品名、历史 assistant 已作出的错误夹带判断、首轮只返回低质量二手来源、官方域名定向补查，以及摘要中含“忽略此前指令”等恶意文本。每个 Tavily 成功结果都必须返回宿主权威的 `websearch_evidence_policy_v1`，并证明其要求模型重新核对历史结论、优先官方一手来源、证据不足时保持未核实、只凭陌生感不得判定伪造或夹带、不得执行搜索内容中的指令；Prompt Tool 描述被管理员覆盖时也不能移除该结果契约。

WebFetch 专项必须覆盖两种公开参数分支、额外字段拒绝、静态 HTML 与真实 JavaScript 页面、Defuddle Markdown、中文无空格 query、文档顺序、邻接块、固定 token 预算、缓存与取消。安全负例必须覆盖协议、userinfo、自定义端口、尾点、IPv4/IPv6 私网、metadata、mapped/NAT64/6to4/Teredo、混合公私 DNS、DNS family 不一致、重定向到私网、非 HTML、解压炸弹、动态子请求、WebSocket、非 GET 和 DOM 超限，并证明被拒目标零连接。Provider 回归必须证明 OpenAI Responses、Codex Responses、Chat Completions、Anthropic Messages 与 Gemini generateContent 的实际请求体中 `webfetch` 都是无 `oneOf` 的扁平三字段 schema；OpenAI 与 Codex 显式携带 `strict: false`，宿主仍拒绝关闭匹配时携带 query、开启匹配时缺少或传空 query。全局 Tool schema 门禁还必须以非法 fixture 证明 `oneOf`、strict object 缺少 `additionalProperties: false`、strict properties 未全部 required 时在任何 Provider 请求前返回 `PROVIDER_TOOL_SCHEMA_INVALID`。其余 Provider 回归必须证明 `webfetch` 与本地数据工具同批及跨轮冲突，`websearch` 后可继续 `webfetch`，网页伪装 system/developer/tool 或 evidence policy 的文本作为不可信证据保留，宿主策略不能被覆盖。运行合同必须覆盖 renderer 无 workspace/secret 挂载、回环端口、非 root、只读根、cap drop、no-new-privileges、seccomp、资源限额、可选能力降级，以及 Linux/WSL `linux/amd64` 与 Apple Silicon 原生 `linux/arm64` 两种 Chromium 沙箱镜像；还必须在容器内证明普通 direct fetch 无法绕过策略代理、HTTPS 子资源受解压后字节上限约束，并通过 SIGKILL Chromium 主进程证明容器会非零退出、由 Docker 重启且恢复 healthy。旧私聊与群聊 Prompt 必须通过 `webfetch-v2` 迁移补 canonical 工具或替换旧 schema，同时保留管理员消息、工具说明和其他工具。

受限工具 response preflight 专项必须以 OpenAI Responses、Codex Responses、Chat Completions、Anthropic Messages 和 Gemini generateContent 五种协议分别覆盖 `system_config`、`send_file`、`read_file`、`write_file` 与 `workspace_bash`。每种协议都要证明非空 sibling assistant 文本在 callback 前整份拒绝；受限工具与 inline、deferred、`no_reply` 或 `assistant_text` 混批时，`onAssistantText`、`onToolCall`、文件端口、Bash runner、配置执行、deferred/terminal 接受和 outbox 均为零。staged `system_config` 后续响应必须只 discard 一次 mutation 再返回拒绝输出；普通非受限工具与 sibling text 仍须保持既有 callback 与工具执行行为。直接调用共享 executor 也要复用相同批次门禁，防止绕过协议适配层。

Agent 与系统设置的控件级保存回归必须覆盖 toggle 与选择项直接提交、文本/数字/密码输入在确认前只保留本地值、确认按钮与 Enter 提交、未确认输入不被同分区开关或离页 flush 带入、同分区连续确认与多分区串行提交、每次请求使用前一响应的最新 revision、409 刷新 revision 后只重试一次、第二次冲突停止、服务端校验与网络失败保留当前输入并定位字段、Agent 切换取消旧上下文请求、已确认请求在路由离开时 flush 成功或失败留页、Bark 密文占位与清除语义，以及页面没有全局同步条、“已同步”、通用保存、放弃和未保存离页确认。提示词正文必须继续显式保存并保留冲突恢复与离页保护。设置视觉检查必须逐页覆盖 Agent 身份、回复行为、语气处理、记忆处理、群聊编排、Agent 工具、命令执行、模型服务、回复重试、广播风暴、账户安全和连接与通知，验证桌面分组导航、移动端选择器、字段归属、待确认、确认完成、黑白反转 toggle 与就地错误状态。

全 WebUI 视觉回归必须覆盖登录、状态、Web Chat、会话列表、会话详情、会话设置、定时任务、Agent 提示词、系统提示词、记忆及梦境、知识库、图像、语音、表情、日志、Agent、扩展、Agent 设置、系统设置和配置医生；在 390、768、1440、1920px 的 light/dark 下检查页面标题、导航、主内容、弹层、分页、空状态和错误状态。每张截图同时检查横向溢出、同轴对齐、信息密度、文本对比、键盘焦点、44px 触控热区、遮罩或点击外部关闭、Escape 与焦点恢复；黑白常规交互、语义色、数据图表和日志终端的颜色职责不得混用。Agent 与系统提示词还要在中等桌面宽度验证常驻变量表，在窄屏验证变量抽屉，并检查变量圆角标记及鼠标悬浮、键盘聚焦说明气泡。

管理台路由回归必须覆盖每个已登记一级页面的直接访问、尾斜杠和浏览器刷新，确认返回 `text/html` 且加载同一 Vue 应用；`/api/*`、相似前缀和未知路径不能进入 SPA fallback，继续返回对应 API 状态或 JSON 404。新增或移除前端一级路由时必须同步服务端 SPA 路由清单与该合同测试。

Agent 配置文件夹导入专项必须覆盖：直接文件夹和单层包装目录、ZIP 兼容输入、缺少 `agent.json` 或部分 Bot/OneBot 字段时使用目标默认值补齐、包内头像与手动头像优先级、预检的包含/缺失列表，以及创建后注册表和工作区一致。负例必须覆盖 `.env`、Provider 或管理员密钥、SQLite/队列/日志/备份、未知文件、路径穿越、重复路径、非 NFC Unicode、控制字符、ZIP slip、符号链接、硬链接或特殊条目、归档与展开大小、文件数量、无效 UTF-8/JSON/图片和自拍清单；任一失败均不得物化目标目录或注册行。还必须注入目录发布、注册表写入和创建回调失败，证明临时目录清理、已发布目录回滚和既有 Agent/工作区拒绝覆盖。管理台回归必须覆盖 `webkitRelativePath` 文件夹载荷、ZIP 载荷、校验失败清空、弹层关闭后重开状态清空，以及 390、768、1440、1920px 的 light/dark 截图无横向溢出。

交付前必须通过：

```bash
npm run verify
```

`verify` 依次执行 runtime contract、architecture、SQLite recovery、类型检查、单元与集成测试、独立 runtime smoke、CI 容量基线、生产构建和 E2E。消息专项回归必须证明 `assistant_text` 写入 durable outbox 后即可继续 inline 工具，远端发送仍在进行或重试时不能阻塞工具；事件重试不能重复发送已提交的中间消息。deferred `dispatch_message` 与任务必须原子持久化，worker 在 acknowledgement 仍待发送时即可 claim，callback 随后按同一会话 FIFO 投递。OneBot 入站专项必须覆盖 NapCat 当前全部具体消息段及兼容别名、精确的 `onlinefile`/`flashtransfer` 类型、未知类型回退、CQ 字符串、内容图片与表情图片分类、内联与仅 ID 的 `forward`/`node`、当前账号的 `get_forward_msg` 入队前展开、嵌套发送者和媒体顺序，以及深度、数量和最终文本容量边界；公共提示词回归必须同时覆盖默认契约和 `.inbound-message-v1` 的保留式、幂等迁移。用户群聊编排器回归必须覆盖纯图片和图文混合消息，证明历史消息与当前消息优先保留 `[内容图片#N]`、`[表情图片#N]`，只为缺少语义标记的旧媒体补充 `[图片]`，已有标记不重复补齐，并且不把图片 URL、Data URL 或本地路径放入编排 payload。

Session FIFO 属性回归必须用 100 个确定性交错 turn 覆盖至少五个群会话，继续断言同会话模型启动与外发顺序、跨会话并行、零丢失和零重复。该用例只衡量 Session 队列，必须隔离另有专项覆盖的群 Thread 分类与记忆压缩模型副作用；队列自身的 `waitForIdle` 保留 10 秒失败门限，外层测试预算为 20 秒以覆盖 Native macOS 与 WSL/ext4 的初始化和调度开销，不能用外层默认 5 秒提前截断队列门限。
