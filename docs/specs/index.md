# sunabot 当前系统规范

版本：2026-07-15
状态：当前实现的唯一规范入口
适用范围：sunabot 后端、多 Agent 运行时、OneBot 接入、管理台、持久化、测试和部署

本索引与下列八个模块共同构成当前系统规范。修改业务代码或配置前，先读取本索引，再读取与修改范围对应的模块；跨模块改动需要同时核对所有相关模块、功能—代码文件索引与验证标准。旧设计和实施计划只存在于 Git 历史，不得按历史方案恢复 JSON/JSONL 持久化。
