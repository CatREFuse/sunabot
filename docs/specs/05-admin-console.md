## 7. 管理台

管理台侧栏分为“Agent”和“公共系统”。Agent 区包含当前 Agent 切换器、Agent 设置、状态、Web Chat、会话、Agent 提示词、记忆、图像、表情、语音、日志和扩展；公共系统区依次包含系统设置、配置医生和系统提示词，配置医生使用独立 `/config-doctor` 页面并位于系统设置下方。Agent 提示词页显示当前 Agent 的六个人格文件和自拍提示词改写，并提供“覆盖系统提示词”开关；开启后同页增加该 Agent 的系统提示词覆盖入口。系统提示词页只编辑公共版本，不显示自拍提示词改写。管理台支持 light、dark 和跟随系统主题，并适配桌面、平板和移动端。切换 Agent 后，会话、Web Chat、图片、表情、语音、记忆、Agent 提示词、Agent 工具、扩展和 Bot 配置只读写所选 Agent；模型配置、共用开关和公共系统提示词保持全局一致。Agent 设置与系统设置不显示分区级同步条，也不使用全局设置同步状态：toggle 和选择项变更后立即串行提交，文本、数字与密码输入先保留在控件本地，点击输入框内的确认按钮或按 Enter 后才进入配置草稿并提交；未确认输入不随其他开关提交，离开页面也不写入。页面只在对应分区就地显示保存失败、冲突或重启生效结果，不显示“已同步”、通用保存、放弃或未保存离页确认。提示词正文继续显式保存并保留未保存离页保护，管理员密码、配置医生修复、危险删除和扩展安装等确认型操作继续使用各自的提交或确认动作。群聊编排器设置以秒显示“启动时间”，默认 60 秒、允许 1—3,600 秒，确认后继续写入 `recentMessageWindowMs`，不迁移现有配置格式。回复行为中的“输入防抖时间（秒）”编辑当前 Agent 的 `bot.replyDebounceMs`，默认 5 秒、允许 1—60 秒，确认后热更新；群聊引用过滤名单接受 QQ 号，命中后仅取消引用，不关闭回复。`no_reply` 工具详情与回复行为页的“no_reply 时戳一戳”共同编辑 `bot.pokeOnNoReply`，任一入口切换后另一入口显示同一值。

Agent 设置的“语气处理”分区独立编辑当前 Agent 的启用状态、Provider、模型、推理强度、Temperature、最大输出 Token 和失败重试次数，并提供 `conversation.tone-rewrite` 的提示词入口；开关和选择项直接热更新，数值输入确认后热更新。Provider 留空时显示“跟随默认 Provider”，Provider 列表只提供已启用项，模型继续支持目录选择与自定义 ID。旧 Agent 配置或旧管理 API 响应缺少 tone 时使用默认关闭配置，设置页保持可用。系统提示词列表包含“语气改写”；当前 Agent 开启系统提示词覆盖后，可编辑对应私有副本，切换 Agent 后配置与私有提示词保持隔离。

Agent 区的“语音”页面固定读写当前所选 Agent。页面提供启用开关、默认语言，以及中文、English、日本語三个语言选项；每个语言独立显示参考音频是否就绪、文件名、参考台词、大小和更新时间，并通过上传弹层选择不超过 8 MiB 的音频和填写 1—1,000 字参考台词。启用前默认语言必须已有参考音频，已启用的默认语言参考音频不能直接删除。设置、上传和删除按控件串行锁定，上传与删除使用各自确认流程，弹层支持关闭按钮、遮罩、Escape、焦点恢复和移动端满宽。页面通过 `GET/PUT /api/voice-profile`、`PUT/DELETE /api/voice-profile/:language` 和 `POST /api/voice-profile/probe` 显式携带 `agentId`；进入页面读取 MOSS-TTS-Nano 状态，管理员也可手动重新检测，探针只显示“可用”“不可用”及检测结果，不暴露服务 URL、响应正文或宿主路径。切换 Agent 时必须关闭上传和删除弹层、取消旧读取并清空旧 Profile、服务状态、忙碌状态和反馈，旧 Agent 的迟到响应不能覆盖当前页面。

系统设置的“回复重试”页编辑公共 `normalReply.maxRetries`，字段为“失败重试次数”，默认 3，允许 0—10；确认后热更新全部 Agent。系统设置的“广播风暴”页编辑公共 `broadcastStorm` 配置，包含“广播风暴嗅探”“检测窗口（分钟）”“回复次数”“静默时长（分钟）”和“补充嗅探账号”；开关直接提交，其他输入逐项确认。补充账号与已启用 Agent 的 QQ 合并参与检测；两项公共配置均由全部 Agent 共用，不写入单个 Agent manifest。管理台读取旧版配置响应时，缺失的 `normalReply` 使用当前默认值，不得因新增配置段缺失导致整个设置页进入错误态。

Agent 区另设“定时任务”页面，固定读写当前所选 Agent。列表显示名称、启停状态、cron/once 计划、下一次与上一次触发时间、最近运行状态和全部回调目标；新建与编辑弹层管理任务上下文、触发计划、既有会话和群聊 @ 对象。重复计划同时提供每隔几分钟、每小时、每天、每周、每月的快捷设置，以及标准五段 Cron 表达式和 IANA 时区输入；单次计划使用明确时间并提交带时区的 ISO 时间。页面通过带 `agentId` 的 `GET/POST /api/scheduled-tasks` 与 `GET/PUT/DELETE /api/scheduled-tasks/:id` 执行 CRUD，通过 `GET /api/conversations` 选择当前 Agent 已有的完整 QQ 会话 ID；更新和删除提交当前 revision，409 冲突保留编辑内容并提示刷新后重试。切换 Agent 时关闭编辑与删除弹层、取消旧请求并清空旧列表，迟到响应不能覆盖新 Agent；页面、列表和弹层支持桌面与移动端 light/dark。系统提示词页同时提供“定时任务回调”入口，用于编辑 `scheduler.cron-callback`。

配置医生页面只检查全局 `workspace/business/config/sunabot.json`，进入页面后通过 `GET /api/config-doctor/scan` 显示“配置正常”“发现可修复问题”或“需要手动处理”，并区分本地规则、语法检查和 AI 诊断来源。本地规则可以形成待确认方案；管理员可通过 `POST /api/config-doctor/propose` 显式请求 AI 复核，并在确认弹层中查看每项路径、动作、服务端计算的目标值和风险后通过 `POST /api/config-doctor/apply` 应用服务端保存的方案。方案绑定源文件 revision、有效期为 10 分钟；配置变化、方案过期或仍有不可修复问题时必须重新检查。页面显示 AI 使用的 Provider、模型和请求目标，应用成功后显示持久备份路径；方案内字段会热更新到当前活动配置，磁盘中方案外的合法变更只落盘并提示重启。当前不提供用户主动回滚操作。

Agent 页面以列表和详情双栏管理 Agent，支持新建 Agent、启停、查看隔离 workspace 与新增多个 QQ 账号。Agent ID 创建后保持稳定，名称可以修改；新建非默认 Agent 的自拍提示词使用通用角色模板，默认 Plana Agent 保留普拉娜专用模板。Agent 身份页可上传或更换仅用于管理台展示的 WebUI 头像，支持 PNG、JPEG、WebP，不限制原图文件大小。选择图片后必须通过圆形裁图弹层调整位置和缩放，保存透明圆形头像；QQ 头像保持独立。QQ 容器区使用“新建 NapCat QQ Docker”入口；提交创建时入口和确认按钮显示带旋转加载图标的“新建中”，移除账号时该行显示带旋转加载图标的“移除中”，两种操作均禁用重复提交。新增、启停或移除 QQ 后，由宿主 account runtime daemon 按注册表调和目标 NapCat 容器，Docker Core 通过 workspace request/result bridge 请求宿主执行且不挂载 Docker socket。未运行账号始终显示“运行”，调用单账号启动接口后创建或启动对应 Compose project；成功后刷新为“待登录”，不能要求重启全部 Sunabot。管理台显示期望状态、实际状态、是否仍需调和和最近错误。注册库不可读时调和失败关闭，不能生成停止或删除计划。每个账号独立扫码、退出和打开对应 NapCat WebUI。Plana 的 `primary` 是固定基线账号，可以退出 QQ 登录，不能从注册表移除；管理 API 对移除请求返回 `PRIMARY_ACCOUNT_REQUIRED`，管理台不显示移除入口，其他离线账号可以移除。

新增 Agent 弹层支持选择配置文件夹；ZIP 仅作为浏览器无法选择目录时的兼容输入。选择后先预检，展示已包含文件与将由目标当前默认值补齐的缺失项；校验失败会清空载荷，关闭后重新打开不保留预检或错误状态。创建提交仍由服务端重复预检并原子发布，手动上传的 WebUI 头像优先于包内头像。

Agent 扩展管理 API 按当前 Agent 提供 Skill 安装、独立安全审查、启停、卸载、跨 Agent 复制预览与原子应用，以及 MCP server 描述符增删改。`POST /api/agent-extensions/skills/:skillId/review` 只接受严格正文 `{agentId,approve:true}`；管理员 session、CSRF 与 Origin 校验完成后才运行摘要绑定的审核事务，成功后关闭该 Agent 的扩展运行生命周期，失败不改变审批状态。Skill 复制必须显式选择 skip、replace 或 rename，复制普通文件树、重新校验并原子发布，不共享 inode，也不复制 MCP secret 或 OAuth 凭据。MCP runtime API 提供目录读取、显式工具调用、resource read/subscribe/unsubscribe 和 prompt get；全部端点复用管理员 session、CSRF 与 Origin 门禁，使用严格字段集合和请求中止信号。MCP OAuth 授权入口只接受 localhost 回调，展示并绑定当前 Agent、server、resource 和浏览器 session，成功后配置仅保存 credential handle。

扩展页固定使用当前 Agent，顶部汇总 Skill、MCP 与一次性批准；页面先读取 overview，再并发读取 MCP 运行状态与批准队列，避免只读状态调和与 Skill 索引恢复争用同一扩展目录。Skill 区提供 ZIP 安装、摘要审查、启停、卸载和跨 Agent 迁移，迁移必须先预览再选择 skip、replace 或 rename。MCP 区提供 stdio 与 Streamable HTTP 描述符的新增、编辑、启停、删除、运行状态和目录详情；stdio 参数与环境变量名称逐行输入，保存前完整展示固定可执行文件与参数并显式确认。OAuth 只打开本机受控授权流程，页面只显示绑定状态和刷新、撤销动作；浏览器不保存 secret、OAuth token、宿主路径或凭据值。待批准 MCP 工具调用以有时限的独立队列展示，批准动作绑定当前 Agent 和 ticket。全部危险删除使用确认弹层，错误留在对应页面或弹层内，页面同时支持 light、dark、桌面和移动端。

复制预览返回的 MCP server 已是最终目标安全形态，并明确显示停用与是否需要重新授权；apply 绑定同一 preview revision、源/目标 Skill revision 与源/目标 MCP revision，不能在确认后重新读取并复制源凭据。stdio 复制保留非秘密 env key 名称，以便目标 overview 显示缺失项；管理员重新确认完整命令并替换描述符后解除迁移状态，全部目标 key 配置完成前仍不能启用。Bearer/OAuth 的目标授权状态为 pending 时，启用请求稳定返回重新授权错误；OAuth 绑定成功只替换目标 Agent 的 handle，仍由管理员显式启用。

登录页使用 Sunabot 品牌 Hero 与管理员登录表单组成响应式双栏，移动端按 Hero、表单顺序纵向排列。用户可见文案只保留名称、状态、动作、结果和完成操作所需的提示；页面不得展示鉴权实现、浏览器存储方式、数据来源、区域职责、设计说明或装饰性状态代码。

设置中的 Agent 工具页默认打开“工具目录”Tab，列出十七个真实工具的图标、名称、Function 名、摘要、配置状态和同步或异步方式，支持搜索、启停与刷新。健康的运行能力不显示状态标记；限定会话的能力以锁图标和中性文案显示适用范围，只有运行环境异常时才以错误语义显示“运行环境异常”及 API 返回的具体原因。详情弹层展示适用会话、Bash 当前私聊执行后端、实际模型描述、描述来源、JSON Schema 参数与严格模式；`no_reply` 详情同时显示“no_reply 时戳一戳”，`system_config` 显示为内置同步工具。工具启停直接提交；模型描述点击“确认”后建立全局覆盖，“恢复继承说明”会删除覆盖。“运行参数”Tab 继续管理单轮调用上限、Tavily、Codex Worker 和图像生成默认值，选择项直接提交，输入值逐项确认。两个 Tab 共用当前工具配置草稿并按确认顺序串行提交。

Agent 工具页只控制当前 Agent 的工具总开关。每条会话列表项、会话详情页和 Web Chat 页均提供“会话设置”入口，进入可深链、可刷新、可返回原会话的独立设置页；QQ 会话包含“回复”和“工具权限”两个分区，Web Chat 只显示“工具权限”。回复分区编辑当前会话的回复开关，真实群聊同时编辑群聊编排器开关；工具权限分区读取并同步当前会话的工具选择。Agent 已停用的工具在会话设置页锁定关闭；健康的运行能力不显示状态标记，会话范围限制使用中性文案，运行环境异常时显示 API 返回的具体原因并保留会话选择。`activate_skill` 与 `read_skill_resource` 的能力状态只反映运行端口是否接线，空 Skill 目录不显示异常。回复与工具权限共用当前页面实例的防抖串行队列，分区内就地显示等待、同步、成功或失败状态，不显示保存、放弃、未保存标记或离页确认；离开页面先刷新队列，失败时保留输入并留在当前页。工具目录必须在当前 Agent 与完整会话 ID 的数据全部就绪后才能编辑；会话或 Agent 切换取消旧上下文请求，工具同步只提交严格的 `disabledTools` 数组。`GET/PUT /api/conversations/:id/tools` 同时支持 QQ 会话 ID 与 `web:admin`，未知工具、重复项、多余字段和无效会话 ID 返回 400。

Agent 身份页只编辑 WebUI 头像，Agent ID 与工作目录只读展示。可配置的记忆容量只有“记忆处理”中的工作记忆上限；长期记忆和用户画像当前不设数量上限。Bash 与 Codex 的启停只在工具目录出现；命令执行页提供管理员私聊 `native`/`docker` 后端、独立审计模型、严格审计、管理员身份门禁和管理员群聊开关，并明确展示群聊固定 Docker 受限模式、Web Chat 不可用和 workbench 边界。已废弃的关键字黑名单与 workspace 开关不能作为有效隔离控制展示。`workspace_bash` 与 `codex` 的工具说明允许覆盖，启停状态不能再写入通用工具覆盖。

`workspace_bash` 的目录状态按所选 Agent 实时读取当前 backend、独立审计 Provider 和隔离 capability；配置启用、策略允许的会话范围与运行可用分开显示，backend 失败不能把管理员私聊或已启用的管理员群聊范围改写成“当前没有可用会话”。Plana 与其他 Agent 统一通过 Agent 配置服务读写 Agent 级 Bash 配置，管理表单、工具目录和运行时不得读取不同配置源。管理员通过设置页或 `system_config` 切换 `native`/`docker` 后，运行时递增配置 epoch；下一次状态查询与下一轮 OneBot 管理员私聊必须使用同一新配置快照完成审计和隔离探针，旧执行 handle 立即失效。API 目录只返回安全裁剪后的 capability、当前 backend、会话范围与稳定原因码，不返回 audit runner、审批上下文、宿主路径或沙箱诊断正文。

状态页使用响应式数据拼盘展示所选 Agent 的 QQ 账号、连接状态、内容计数、Provider 健康，以及当日 Token 总量、输入、缓存输入、缓存率、输出和请求数，并可切换“当前 Agent”与“全部 Agent”。Provider 状态使用统一 probe，显示“已验证可用”“当前不可用”或“未配置”，已保存密钥不能覆盖失败的健康结果。全部 Agent 视图只汇总 Token、请求数、在线 Agent 和在线 QQ 数，不混合展示会话、记忆或人格数据。拼盘保留非对称网格，通过留白、分割线和连续数据区组织信息，不使用圆角卡片逐项装箱。Token 统计使用浏览器传入的时区偏移：当日小时序列固定返回 0—23 点 24 个桶，缺少的小时补零；日视图固定覆盖截至当日的最近 53 周本地日期，缺少的日期补零。用户可在小时图与日历热力图之间切换，并按模型和回答、编排器、记忆、其他功能组合筛选；汇总指标与当前图表始终使用同一筛选范围，未标注模型作为独立选项。小时图使用 Token 总量柱形和缓存率折线，缓存率为 `null` 时显示 `--` 且折线跳过该点。四位到六位主指标使用 K 缩写，百万级主指标使用 M 缩写，千分位精确值保留在主数字的悬停提示中，不在数字下方重复显示。

页面信息区默认通过留白、连续网格和 1px 分割线建立层级；按钮、输入控件、消息气泡和必要弹层可使用与语义相称的技术圆角。Boxicon 不使用背景、边框或圆形外壳，44px 点击热区保持透明，需要加强层级时直接放大图标。中文页面标题使用 Space Grotesk Variable 与系统中文字体，运行主状态使用英文并以 Doto Variable 显示，状态页所有大号统计数字统一使用 Doto Variable，标签和元数据使用 Space Mono。

Web Chat 使用固定管理员身份和 `web:admin` 会话，通过 Web delivery adapter 进入与 QQ 相同的 Agent loop、提示词、记忆和同步工具链。每个 Agent 长期复用一套 Web Chat 顺序执行状态，消息 ID 和并发回合不能在 HTTP 请求之间重置；模型调用必须进入该 Agent 的运行上下文，使请求日志与 Token 聚合写入对应 Agent 数据库。Web Chat 回复只能写回浏览器消息流，不能经 OneBot 外发；Web Chat 也不能进入 QQ 会话目录、上线通知或 OneBot 外发目标。当前 Web delivery 没有持久化的异步结果投递目标，因此 Web Chat 不向模型提供 Codex、生图、自拍或语音工具；`system_config` 的设置、状态和已知群聊分页查询可用，群聊分页只读取所选 Agent 的安全字段，修改返回明确的 durable delivery 不可用错误且不得暂存。已经受理的 Web Chat 回合使用服务端超时并按顺序完成，不绑定浏览器请求体或页面生命周期。发送接口拒绝空白正文和超过 16,000 字符的正文，页面支持 Enter 发送、Shift+Enter 换行、发送中状态、错误恢复、非重叠消息轮询和图片缩略图。

日志页按从新到旧提供 Bot 活动终端与分页纵向时间轴，Responses、Codex Provider、Deferred Codex CLI、Chat Completions、Anthropic 和 Gemini 请求同时显示中文标题与原始 action ID，其中 Codex CLI 使用 `codex.tool.complete`。模型响应的统一 `tokenUsage` 使用独立用量条展示，实际请求体、Provider 返回 payload 和 usage 字段继续使用递归结构化视图，不能退回整段 JSON 文本。日志页汇总回答、群聊编排、记忆压缩和其他模型调用的次数与 Token；记忆压缩区分工作与长期记忆、用户画像。非私聊会话详情显示会话累计消息数、当前保留消息数、可见消息数、用户消息数、回答数、内部消息数，以及同口径模型调用统计；页面可见且会话已选中时每 10 秒刷新统计。会话请求日志侧边栏提供本地全文匹配，按不区分大小写的子串同时搜索当前已加载日志的 action、模型、请求体、响应体和元数据，显示匹配数并保留递归结构化结果；未命中时显示“没有匹配的请求日志”。Bot 消息气泡显示消息来源、本轮实际工具和请求日志入口，工具图标不使用背景或边框，窄屏时允许整行换行。记忆页一次只查看一个真实来源，单个搜索栏在本地筛选与语义召回间切换。提示词编辑器提供变量表、已使用变量状态、可选 XML 包装，以及离开前保存；群聊回复的变量表包含 `conversation.group.thread_context`，私聊和群聊回复都包含 `conversation.voice.settings` 与 `conversation.voice.trigger_policy`，管理员可直接编辑变量所在消息的角色、位置与包装。Function Tool 的描述编辑器使用同一变量插入和 XML 包装控件，使 `send_voice_message` 的配置说明与运行时变量保持可编辑。已登记变量引用复用 inline code 的底色与文字样式，未登记变量保持普通文本样式。高亮镜像层不得改变字体度量、字符推进宽度或行内布局，光标与可见文本位置必须一致。

会话列表与详情的标题来自当前会话所绑定 QQ 账号的好友或群目录显示名；多 Agent、多 QQ 之间不能复用其他账号的备注或目录结果，Core 重启后继续读取按账号隔离的可重建目录缓存。所有新会话默认关闭回复，首条入站消息先建立会话记录并遵守关闭状态，管理员开启后才创建回复任务；已有会话保持原回复状态。保存“启用”或“编排器”只更新开关字段，不得用运行时持久化记录覆盖标题、群名、昵称或备注。

会话详情使用一体化标题栏组合会话身份、标题、回复与群聊编排开关、Token、消息数、编排器窗口和工具入口；开关位于标题下方，设置、刷新和请求日志固定在最右工具区。Token 每满或进入下一个 1M 显示一个连续计量格，消息每满或进入下一个 100 条显示一个连续计量格，格数不设展示上限；编排器窗口把实时秒数、点阵上限、状态和竖条进度放在同一 widget，达到上限后显示值封顶并进入判断状态。编排器在回复关闭时保留显示并禁用，窗口 widget 同步显示关闭并停止计时。完整模型、行为、记忆与消息统计点击 Token widget 后在右侧栏展开，不常驻占用消息空间。标题栏按自身可用宽度响应式重排，中间宽度弹性收缩，窄屏改为标题工具区与三项数据区上下两层，不能裁切右侧 widget 或产生页面横向滚动。会话设置也使用右侧栏，包含回复控制、会话信息和工具权限；回复与工具开关点击后立即同步并生效，工具权限继续受 Agent 总开关约束。设置栏与 Token 详情栏的关闭按钮都位于左上角；侧栏支持遮罩关闭、Escape、焦点恢复和移动端满宽适配。

图片列表和会话正文先读取 48px 低质量 WebP 占位图并以高斯模糊显示，再淡入 480px WebP 展示图；用户打开预览或原图链接时才读取完整图片。生成历史使用紧凑响应式网格，移动端 2 列，随后随视口扩展为 3、4、5、6 列。浏览器缓存已加载资源，图片历史在短期页面切换中复用，返回图片页不重新批量请求占位图和历史数据。

图像页的自拍参考区按当前 Agent 直接管理最多 9 张素材，并明确显示“素材库最多 9 张，每次自拍选用 1–3 张”；不得再用独立主管理弹层重复展示同一图库。素材在移动端、平板和桌面端分别使用紧凑的 3、6、9 列，以备注作为主标题，保留文件名、尺寸和大小作为次级信息；添加图片直接进入逐图备注，编辑、预览和删除从对应素材就地发起。多选上传必须先为每张图片填写备注；备注的原始输入先拒绝 C0/C1 控制字符（含首尾 Tab、CR、LF）和孤立代理项，再执行 NFC 规范化与 trim，最终要求 1—120 个 Unicode code point；已有备注可以单独编辑。切换 Agent 后列表、上传、修改、预览和删除请求全部切换到所选 Agent，light/dark 与窄屏页面和必要操作弹层均不得横向溢出。

表情页按当前 Agent 分为“预设表情”和“自定义表情”，使用 96px 预览的紧凑横向列表并显示已安装数量；每项可一键生成、点击或拖入图片上传/替换、就地修改 key、查看历史版本和删除，缺少图片的预设 key 直接显示一键添加入口，自定义 key 在新增弹层中校验。单个 Agent 最多 64 个表情，上传限制为 8 MB 的 PNG、JPEG 或 WebP，生成时缺少自拍参考图、Provider 不可用、同 key 正在生成、规范化繁忙或图库已满都显示对应结果并允许安全重试。每个 key 最多保留 20 条内容寻址版本记录；当前版本不能从历史弹层删除，删除旧版本只移除图库历史元数据，底层内容文件继续保留供已进入 durable outbox 的消息发送。列表先读取 32px 占位图，再读取 640px 展示图，打开原图时才请求完整 PNG；当前与历史内容 URL 都绑定 `agentId` 和文件名版本，同 key 替换后 URL 必须变化，旧版本只返回对应旧内容，不能在 immutable 缓存期展示错误图片。管理员可为当前 Agent 选择 64、128、256、512 或 1k 的发送尺寸，运行时只缩小经过摘要校验的原图并按内容摘要复用缓存，默认 512；设置和表情数据均按 Agent 隔离。管理台只把每次 mutation 的响应作为操作成功确认，随后以当前 Agent 的 canonical GET 刷新列表；切换 Agent 或后续请求开始后，旧 mutation 和旧 GET 的晚返回都不能覆盖新状态。删除使用确认弹层，版本历史、编辑和删除弹层支持遮罩、Escape、焦点恢复、light/dark 和移动端满宽布局。

QQ 登录由管理台按 Agent 和账号完成：容器未运行时先显示“运行”，启动成功后显示“登录”；离线时直接显示对应 NapCat 的当前二维码并每 2 秒拉取新状态，二维码轮换后页面自动替换；用户可以主动刷新二维码。在线时显示当前账号并提供带确认的退出操作，退出后对应 NapCat 自动回到扫码态。扫码成功后 Core 把 QQ 号写入 `agent_accounts`，NapCat 把快速登录账号写入该账号目录的 `account.env`，并清理临时二维码和手动登录标记，后续重启恢复快速登录。原生 WebUI 只保留为故障诊断入口。

管理台页面脚本随主应用一次加载，路由切换不得再请求页面脚本分块；鉴权启动期间使用统一加载状态。主题预加载使用同源静态脚本并在应用脚本前执行，保持 `script-src 'self'` 且不依赖内联脚本；字体与图标由构建产物本地提供，字体保持独立同源资源，不内联为 `data:`，也不依赖外网字体服务。带内容哈希的构建资源使用长期缓存，入口 HTML 禁止长期缓存。浏览器不得因等待脚本或原图而表现为点击无响应。

管理 API、生成图片和管理台数据使用管理员账号密码建立的 HttpOnly 会话鉴权；Cookie 最长保留 30 天，空闲 7 天失效，服务端以 SHA-256 哈希在主库持久化会话，Core 重启后继续识别。写操作还必须通过 CSRF 与 Origin 白名单校验。设置页提供管理员密码修改，成功后轮换当前 Cookie 与 CSRF Token、清除其他会话并保持当前浏览器登录。Bearer Token 仅用于受控自动化客户端，本机回环请求不绕过认证。远程入口包含单来源锁定、全局自动熔断和文件型手动熔断。远程图片代理必须执行协议、域名、DNS、重定向、响应类型、content-length、总字节数和超时校验；生产默认使用系统 DNS 解析并在每次重定向前复验，测试替代解析只能通过显式依赖注入，解析为空、失败或包含未受信私网地址时必须在 fetch 前失败关闭。
