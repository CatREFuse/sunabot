# Agent 灵魂包往返

## 用户目标

已认证管理员可以把当前 Agent 的全部人格范围提示词导出为一个 `.sunabot-soul.json` 文件，并在预览差异后导入目标 Agent；导入前后人格内容保持一致，目标 Agent 的身份、账号、业务数据和运行资源保持不变。

## 角色与环境

- 角色：已认证管理员。
- 环境：隔离 Workspace；包含来源 Agent `arona` 与目标 Agent `plana`。
- 入口：Agent 提示词页面与本机 `sunabot.sh soul` 命令。

## 输入

1. 在 Agent 提示词页面导出 `arona` 的灵魂包。
2. 使用页面选择该文件并查看导入预览。
3. 在预览完成后修改目标 Agent 的一个人格文件，再确认导入。
4. 重新预览并确认导入。
5. 使用 CLI 执行 `inspect`、`export` 和 `import`，覆盖交互确认与非交互确认。
6. 分别提交未来版本、缺失项、重复项、未知项、文件名不匹配、摘要不匹配、非法提示词变量和超限文件。

## 预期结果

- 导出文件使用严格 `sunabot.soul` version 1 schema，只包含当前 Prompt Catalog 中全部 `scope=persona` 文件的 `id`、`fileName`、`kind`、`content` 与 `sha256`，以及不会应用到目标 Agent 的来源名称和来源 ID。
- 导出文件不包含 `agent.json`、管理员身份、Provider 或密钥、SQLite、QQ/NapCat、workbench、记忆、头像、自拍参考图、其他自拍素材、绝对路径和运行日志。
- 预览返回来源信息、文件清单、内容变化和绑定目标文件 revision；预览期间目标 revision 变化后，确认导入返回冲突且所有文件保持原样。
- 有效导入在同一事务中替换全部人格范围文件并只执行一次运行时 reload；任一暂存、提交或 reload 失败时全部文件恢复，无法证明恢复完成时进入现有 recovery 状态。
- 导入成功后再次导出，全部人格条目的 `id`、`fileName`、`kind`、`content` 与 `sha256` 和原包一致。
- 导入不会修改目标 Agent 的 ID、名称、启用状态、管理员信息、Provider 配置、QQ 账号、业务数据库、记忆或 workbench。
- WebUI 在桌面、移动端、light mode 与 dark mode 中均可完成选择、预览、取消和确认；弹层支持遮罩、Escape 与焦点恢复。
- CLI 不接受明文密码参数，不在标准输出或错误中显示提示词正文；非交互导入缺少明确确认时稳定拒绝。

## 质量标准

- 管理员在确认前可以准确看到来源、目标和每个文件的变化状态。
- 校验错误定位到具体条目，且不包含提示词正文、宿主绝对路径、凭据或堆栈。
- 成功提示只显示导出、预览或导入结果，操作期间不能切换到错误的 Agent 上下文。
- 失败导入不留下部分更新、临时文件或备份文件。
