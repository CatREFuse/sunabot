# 日志业务节点筛选与请求详情

## 用户目标

已认证管理员可以按业务节点查看当前 Agent 的日志，快速定位失败和重试，并在单条日志详情中核对脱敏后的请求体、Tool Call 与返回体。

## 角色与环境

- 角色：已认证管理员。
- 环境：隔离 Workspace；准备包含 OneBot 心跳、私聊、群聊、旧记忆压缩、记忆工具和 Dream 的请求日志与 OneBot 事件。
- 页面：当前 Agent 的“日志”。
- 视口：`1440×900`、`390×844`。
- 主题：亮色、暗色。

## 输入

1. 打开日志页，依次选择“全部”“OneBot 心跳”“私聊对话”“群聊对话”“记忆压缩”“记忆记录”“梦境”。
2. 在“记忆记录”中依次选择“全部”“工作记忆”“读空气”“用户印象”。
3. 打开一条成功日志、一条失败日志和一条发生重试的日志。
4. 展开请求体、Tool Call、返回体和元数据中的嵌套对象、数组与长文本。
5. 切换分页、刷新页面并切换当前 Agent。

## 预期结果

- 除 OneBot 心跳沿用最近事件缓冲外，主业务 Tab 只显示所选节点的数据，分类在服务端分页前完成，数量与页数属于当前筛选结果。
- “OneBot 心跳”只显示心跳事件及其原始事件详情，不混入其他 OneBot 元事件。
- 私聊与群聊保留同一次调用关联的模型请求、Tool Call、模型响应和运行记录。
- “记忆压缩”可以查看历史独立记忆 Provider 日志；当前没有此类运行时任务时显示空状态。
- “记忆记录”中的工作记忆对应 `add_workmemory`，读空气对应 `read_air`，用户印象对应 `add_user_profile`；二级筛选不会把三类工具混在一起。
- Dream 日志包含生成、整理、重试和失败记录。
- 单条日志头部显示业务节点、动作、Provider、模型、时间、结果和重试次数；失败状态使用红色值和 `[ERROR]`，无整行红底。
- 请求体、Tool Call、返回体和元数据分别呈现；嵌套字段可展开，长文本保留换行并可复制。
- Tool Call 显示工具名、调用 ID、参数和结果；记忆正文、用户画像正文、称呼、凭据、Token、宿主绝对路径与受保护文件正文继续使用现有安全投影。
- 刷新、分页和切换 Agent 后保留当前业务节点筛选；筛选结果为空时显示明确空状态。

## 质量标准

- 管理员能在三次点击内从业务节点进入失败请求的请求体、Tool Call 和返回体。
- OLED 黑与暖白主题具有相同的信息层级、对比度和操作能力。
- 页面使用开放式列表、方形分隔线和等宽数据标签，不出现阴影、渐变或圆角卡片堆叠。
- 390 像素宽度下业务 Tab 可横向滚动，详情字段不溢出视口，所有按钮保持至少 44 像素触控区域。
- 历史日志缺少新增分类或重试字段时仍可读取，并显示稳定的兜底分类与零重试。
