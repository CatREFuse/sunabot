# 会话图片与头像恢复

## 用户目标与环境

管理员群聊，Linux/WSL Native Core、Node 24 与独立 NapCat。管理员在会话详情查看 QQ 图片与头像，图片加载成功，头像不产生无效缩略图请求。

## 输入与验证

隔离 HTTP 服务提供 PNG，管理 API 使用生产默认图片传输，仅注入固定 DNS 结果。分别验证 IPv4、IPv6 与 IPv4 混合解析，原图和缩略图均返回可解码图片。前端挂载真实图片组件，验证远程图片和生成图片使用缩略占位，而 `/api/` 头像、data 与 blob 来源不请求缩略占位。显式占位图继续生效。

## 预期工具与输出

无需模型工具或外部 Provider。DNS 验证后的地址直接用于连接，不再次解析域名；Node 自动地址族选择获得正确的地址数组，保留原有超时、重定向和图片大小校验。

## 质量标准与验收边界

真实 HTTP 回归覆盖默认 Undici 传输，组件回归覆盖加载状态与请求路径；管理台 light/dark 截图检查图片显示与布局。生产验收读取当前 QQ 会话图片并验证原图、缩略图和头像响应，过期腾讯图片链接独立标记。此用例不证明 QQ 静默掉线已经根治。
