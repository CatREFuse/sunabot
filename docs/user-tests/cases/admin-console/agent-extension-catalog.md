# Agent 扩展目录可查看

## 用户目标

管理员在当前 Agent 的“Agent 工具”和“扩展”页面查看工具、Skill 与 MCP 服务，并在 Workspace 出现正常运行目录变动后继续使用这些页面。

## 角色与环境

- 角色：已认证管理员。
- 环境：隔离 Workspace；当前 Agent 已初始化工具、Skill 与 MCP 索引。
- 前置动作：扩展服务完成一次目录读取后，在 Workspace 根目录创建一个无关的普通运行目录。

## 输入

1. 打开“设置 → Agent 工具”。
2. 打开“扩展”。
3. 在 Skill 与 MCP 区域之间切换并刷新页面。

## 预期结果

- Agent 工具页显示工具目录，不出现“Agent 扩展目录在操作期间发生变化”。
- 扩展页显示当前 Skill 与 MCP 服务；空目录显示对应空状态。
- Workspace 根目录 inode 或规范路径被替换时仍失败关闭。
- Skill、MCP、Workbench 受控目录在单次操作期间发生替换时仍失败关闭。

## 质量标准

- 页面名称、状态、动作和结果清楚完整。
- 不显示宿主绝对路径、目录 inode、堆栈或内部校验字段。
- Light mode、dark mode 与移动端页面均可正常查看。
