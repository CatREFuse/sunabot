# 旧配置可正常打开设置页

## 用户目标

管理员升级 Sunabot 后打开“Agent 设置 → 回复行为”，可以查看并修改现有设置，不会因旧 Agent 配置缺少新字段而进入错误页。

## 角色与环境

- 角色：已认证管理员。
- 环境：隔离 Workspace；Agent 配置包含既有回复设置，但不包含回复模型、推理强度和读图设置。
- 浏览器：桌面与移动端各验证一次，并分别覆盖 light mode 与 dark mode。

## 输入

1. 打开“Agent 设置 → 回复行为”。
2. 查看回复模型和读图设置。
3. 刷新页面。

## 预期结果

- 设置页正常显示，不出现 `“undefined” is not valid JSON`。
- 回复模型显示 `gpt-5.5`，推理强度显示“中”。
- “生成图片描述”默认开启，Provider 显示当前默认 Provider，读图模型显示 `gpt-5.5`，推理强度显示“低”。
- 页面加载不会自动提交配置；刷新后仍可正常查看其他设置分区。

## 质量标准

- 页面只显示设置名称、当前值、状态和操作。
- 默认值与新建 Agent 一致，不覆盖旧配置中已经存在的值。
- 390、768、1440 和 1920 宽度下无横向溢出，light mode 与 dark mode 的文字和控件均清晰可辨。
