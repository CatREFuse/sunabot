# Agent 切换与 QQ 接入

## 目标与环境

已认证管理员在管理台操作两个 Agent，每个 Agent 对应一个 QQ。使用隔离 API 夹具，不向 QQ 或外部模型发送消息，不重启生产服务。

## 操作与预期

1. 概览显示各 Agent 的切换按钮；选择另一 Agent 后，QQ 身份、连接状态、联系人和统计均跟随，页面没有 QQ 账号下拉框。
2. 全部 Agent 仅用于汇总统计；返回某个 Agent 后显示该 Agent 的 QQ，不改变账号归属。
3. Agent 设置的「QQ 接入」集中显示账号操作、本地自启动或远程托管、运行主机、OneBot 地址与端口、管理端口和自启动状态。
4. 本地模式显示本机运行信息；远程模式显示远端主机和 SSH 转发后的 OneBot 地址，同时显示 Core 监听地址。任何响应和页面不得包含令牌、SSH 私钥或密钥路径。
5. QQ 未登录、OneBot 已连接、状态读取失败分别显示；不能仅凭容器运行或 WebSocket 已连接显示 QQ 在线。
6. 切换 Agent 时清除旧状态、关闭旧登录弹窗，迟到请求不得覆盖新 Agent；卸载后停止轮询。
7. 已有 QQ 时不再显示新建第二个 QQ 的入口；没有 QQ 时保留接入入口，不删除或迁移现有数据。
8. 桌面与手机、明暗主题下可读、无横向溢出；菜单点击外部收起。

## 验证与质量

后端单元测试验证本地、远程、非默认端口及秘密字段排除；浏览器夹具验证 Agent 切换、接入页、状态分离与错误展示。独立夹具评审核对准确性、可用性、账号隔离与文案。真实部署和重启另行确认，mock 验证不能替代真实 QQ 收信。
