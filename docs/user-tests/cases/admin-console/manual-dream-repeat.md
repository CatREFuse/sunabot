# Dream 重复手动触发

## 用户目标

已认证管理员可以在管理台随时手动启动所选 Agent 的 Dream；当天已经完成过 Dream 时，点击“立即做梦”仍会使用当前最新记忆重新运行，不再显示“今天的 Dream 已完成”。

## 角色与环境

- 角色：已认证管理员。
- 环境：隔离 Workspace；所选 Agent 已有一条当天完成的 Dream 记录，并准备完成后新增的工作记忆。
- 页面：当前 Agent 的“记忆 → 梦境”。
- 视口：`1440×900`、`390×844`。
- 主题：亮色、暗色。

## 输入

1. 打开当天已经完成 Dream 的所选 Agent 记忆页。
2. 点击“立即做梦”，等待本轮完成。
3. 在同一自然日新增一条工作记忆，再次点击“立即做梦”。
4. 在一轮 Dream 仍在运行时再次尝试触发。

## 预期结果

- 完成状态不禁用“立即做梦”，也不返回 `DREAM_ALREADY_COMPLETED`。
- 每次接受手动触发时重新捕获当前工作记忆、长期记忆与安全上下文，不复用上一轮完成记录的输入或模型输出。
- 当天记录重新进入 `running`，清空上一轮输出、结果和完成时间；本轮拥有独立的三次自动尝试预算，完成后历史展示当天最新梦境。
- 每次被接受的手动运行只排入一次新的管理员入睡通知。
- 同一 Agent 已有有效 Dream 租约时继续返回 `DREAM_BUSY`，不并发调用 Provider，不重复写入记忆。
- 自动 04:00 调度仍按系统时区自然日运行；手动重复触发不创建历史欠账，也不改变其他 Agent。

## 质量标准

- 管理员在当天完成状态下只需一次点击即可重新启动 Dream。
- 状态区只显示当前触发结果，不再残留“今天的 Dream 已完成”。
- 桌面端和移动端按钮均保持可见、可操作，触发中显示“做梦中”并阻止重复点击。
- 失败信息不包含 Provider 原文、凭据、宿主路径或堆栈。
