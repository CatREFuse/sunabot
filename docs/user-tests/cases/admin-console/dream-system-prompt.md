# Dream 提示词可编辑

## 用户目标

管理员可以在“系统提示词”中找到并编辑 Dream 提示词，也可以从“Agent 设置 → 记忆处理”直接进入该提示词。

## 角色与环境

- 角色：已认证管理员。
- 环境：隔离 Workspace，公共系统提示词中包含 `memory_dream.json`。
- 浏览器：桌面与移动端分别覆盖 light mode 与 dark mode。

## 输入

1. 打开“系统提示词”。
2. 在“记忆”分组选择“梦境整理”。
3. 修改提示词正文并保存。
4. 打开“Agent 设置 → 记忆处理”，点击 Dream 的“编辑正文”。

## 预期结果

- “系统提示词”的“记忆”分组显示“梦境整理”和 `memory_dream.json`。
- 选择后显示 Dream 的 system 与 user 提示词槽位。
- 保存后重新打开仍显示已保存正文。
- “记忆处理”的 Dream 入口进入 `/system-prompts/memory.dream`。

## 质量标准

- 页面只显示提示词名称、文件名、正文、变量、状态和操作。
- 桌面与移动端均可完成查找、编辑和保存。
- light mode 与 dark mode 下文字、焦点和保存状态清晰可辨。
